### 3.2. Составление ручных цепочек инструментов (Workflow)
**Кейс: Комплексная подготовка материалов к уроку «Биология: Клетка»**
1. **Этап 1: Проектирование (GigaChat).** Генерация структуры урока и текста лекции. *Действие:* Ввод промпта с темой. *Результат:* Текстовый план ([lesson_plan.md](examples/lesson_plan.md)).
2. **Этап 2: Контроль (DeepSeek).** На основе лекции из этапа 1 создаем тест из 5 вопросов. *Действие:* Запрос на создание вопросов с ключами. *Результат:* Текст теста ([test_questions.md](examples/test_questions.md)).
3. **Этап 3: Визуализация (Шедеврум).** Создание иллюстраций клетки для презентации. *Действие:* Генерация картинки по промпту. *Результат:* Изображение в формате PNG.
4. **Этап 4: Интерактив (Online Test Pad).** Копирование вопросов в конструктор. *Действие:* Перенос текста теста. *Результат:* Онлайн-ссылка для учащихся.

### 4.2. Выводы
1. Для разработки методических материалов (планов, писем) на русском языке наиболее эффективен **GigaChat**.
2. Использование **Open-Source решений** критически важно для защиты персональных данных учащихся и приватности.
3. Качество визуального контента ИИ (как в **Шедевруме**) отлично подходит для мотивации, но требует контроля на научную точность.
4. Связка нескольких ИИ-инструментов (Workflow) позволяет сократить время на подготовку к урокам до 70%.
5. Зарубежные модели (как **DeepSeek**) пока лидируют в составлении логически сложных тестов и работе с кодом.
