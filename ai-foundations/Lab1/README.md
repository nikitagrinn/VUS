## Задание 3. Анализ дополнительных возможностей

### 3.1. Выявление неочевидных задач
1. **Генерация идей для школьных проектов:** ИИ помогает быстро набросать темы для проектной деятельности.
2. **Адаптация текста:** Пересказ сложного параграфа простыми словами для учеников.
3. **Создание субтитров:** Автоматический перевод видео в текст для создания методичек.

### 3.2. Составление ручных цепочек инструментов (Workflow)
1. **GigaChat:** Пишем текст лекции и подробный план урока.
2. **DeepSeek:** На основе текста лекции создаем проверочный тест.
3. **Шедеврум:** Генерируем уникальные иллюстрации для слайдов.
4. **Online Test Pad:** Сборка итогового теста для учеников.

## Задание 4. Сравнительный анализ

### 4.1. Сравнение языковых моделей (LLM)
| Критерий | GigaChat | YandexGPT | DeepSeek |
|---|---|---|---|
| Качество рус. языка | Отличное | Отличное | Хорошее |
| Доступность в РФ | Высокая (без VPN) | Высокая (без VPN) | Высокая (без VPN) |
| Понимание логики | Хорошее | Хорошее | Отличное |

### 4.2. Выводы
1. Для разработки методических материалов на русском языке удобнее всего использовать **GigaChat**.
2. Для создания визуального контента **Шедеврум** — самое быстрое решение для учителя.
3. Использование связки инструментов (Workflow) позволяет сократить время на подготовку к урокам в 3-4 раза.
