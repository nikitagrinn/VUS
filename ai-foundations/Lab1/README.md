### 3.2. Составление ручных цепочек инструментов (Workflow)
**Кейс: Комплексная подготовка материалов к уроку «Биология: Клетка»**
1. **Проектирование контента (GigaChat):** Генерация структуры урока и текста лекции. *Результат:* Текстовый файл с планом (lesson_plan.md).
2. **Создание контроля (DeepSeek):** На основе лекции из этапа 1 создаем тест из 5 вопросов. *Результат:* Список вопросов с ключами (test_questions.md).
3. **Визуализация (Шедеврум):** Создание уникальных иллюстраций клетки для вставки в презентацию. *Результат:* Изображение в формате PNG.
4. **Интерактив (Online Test Pad):** Копирование вопросов из этапа 2 в конструктор. *Результат:* Онлайн-ссылка на тест для учащихся.

### 4.2. Выводы
1. Для разработки методических материалов (планов, писем) на русском языке наиболее эффективен **GigaChat**.
2. Использование **Open-Source решений** (через Ollama) критически важно для защиты персональных данных учащихся.
3. Качество визуального контента (как в **Шедевруме**) отлично подходит для мотивации, но требует контроля учителя на научную достоверность.
4. Связка нескольких ИИ-инструментов позволяет сократить время на рутинную подготовку до 70%.
5. Зарубежные модели (например, **DeepSeek**) лучше справляются с логически сложными тестами и аналитикой.
